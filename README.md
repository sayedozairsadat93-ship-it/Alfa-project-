# Alfa Project

This repository contains a lightweight custom WordPress theme for a premium event/community website.

## Theme folder

- `alfa-event-theme/` — installable WordPress theme

## Install theme

1. Zip the `alfa-event-theme` folder.
2. In WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
3. Activate the theme.
4. Set the site title, tagline, and navigation menu under Appearance > Customize and Appearance > Menus.

## Theme features

- Responsive hero and landing page layout
- Sticky header with mobile navigation
- Mission/support cards
- Feature/attraction grids
- Sponsor and partner sections
- CTA banner and contact form
- Accessible focus styles and reduced-motion support
- Clean custom CSS variables and WordPress-friendly structure

## Notes

This is a solid starter build for the specification and can be expanded into a fuller multi-page theme with more Gutenberg patterns, template files, and custom block controls.
